| Folder | What is in it |
|---|---|

| `design/` | Early design notes: recording format, operator UX, safety case |
| `evidence/` | The 2026-10-06 lab logs, the only real-arm run of Stack 2 (its home attempt failed) |

| `reports/` | Past status reports, indexed in `reports/INDEX.md` |
| `project/` | Project log and backlog |
| `requirements/`, `lab-info/` | Older requirement baselines and lab notes |
